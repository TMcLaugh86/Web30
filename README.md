**Web30** is a mobile-first, interactive 30-day web development learning platform packaged as a single self-contained HTML file. Instead of isolated syntax drills, every daily lesson adds a real section, responsive layout, or interactive JavaScript feature to a personal portfolio website you can export and deploy live on Day 30.

---

## Key Features

- **30-Day Project-Based Curriculum:** Bite-sized daily lessons organized across four progressive phases—HTML Structure, CSS Styling, DOM & JavaScript, and Launch—worth `+100 XP` each.
- **Live Browser Sandbox (Playground):** Built-in HTML, CSS, and JavaScript code editor with instant rendering, **Mobile (`375px`)** and **Desktop (`100%`)** responsive viewport toggles, and a live **Console Output** panel.
- **WebBuddy Offline AI Tutor:** Integrated coding mentor providing instant answers and contextual lesson hints on semantic HTML, Flexbox, Grid, DOM events, and static hosting—no API keys or internet connection required.
- **Gamified Progress & Milestones:** Tracks daily streaks, total XP, overall site readiness percentage, a 30-Day Build Map, and four unlockable milestone badges.
- **One-Click Website Export:** Bundles your finished `index.html`, `style.css`, `script.js`, and a deployment guide into `my-website-web30.zip` via JSZip (with a standalone single-file HTML fallback) ready for Netlify Drop or GitHub Pages.
